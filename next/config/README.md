# Shipped configurations

Every host reaches the daemon through `tsm-relay` over stdio. The first relay (or `tsm`) that finds no daemon starts one, so none of these needs a supervisor; the units are for keeping the daemon up across logins and crashes. `--scope` names the sessions a host sees: two hosts with different scopes never share a `main`.

| File | For |
|---|---|
| `agent-framework.recipe.json` + `agent-framework.gate.json` | connectome agents: the `mcplServers` entry for a recipe (replace `AGENT` with the agent's name, so each agent has its own scope) and the policy to merge into the agent's `_config/gate.json`, above its broad defer rules (first match wins). It enables `terminal.tools` and `terminal.events`, so a command that ends after its call returned, a program waiting for input, a shell that exits and a pattern the agent asked for wake the agent, and nothing else does. `reconnect: true` starts a new relay when the daemon goes away; the relay itself never reconnects. |
| `mcpl-bridge.json` | Claude Code through `mcpl-cc-bridge`: merge the `terminal` entry into your bridge config (`$CLAUDE_PROJECT_DIR/.mcpl-bridge.json` or `~/.claude/mcpl-bridge/config.json`). The same two feature sets and the same four wakes. Allow the tools with one permission entry: `mcp__plugin_mcpl-bridge_mcpl__terminal__*`. |
| `mcp.json` | Plain MCP hosts (Cursor, Claude Desktop, Claude Code without the bridge). They get the eight tools and no wakes: `look` with `until` is how they wait. |
| `termd.service`, `com.animalabs.termd.plist`, `termd-launch.sh` | Supervising the daemon with systemd or launchd. Both run `termd-launch.sh`, which finds node where Homebrew, Volta or nvm put it (nvm's default version, as `nvm use` would pick it; a supervisor's PATH has none of them), or the one `TSM_NODE_BIN` names, puts those directories on PATH and starts in `$HOME`. Replace the `PACKAGE` (and in the plist `YOU`) placeholders. |

The daemon's socket is `$XDG_RUNTIME_DIR/terminal-sessions/daemon.sock`; where that variable isn't set, `/run/user/<uid>/terminal-sessions/daemon.sock` on Linux when that directory is yours alone; otherwise `/tmp/terminal-sessions-<uid>/daemon.sock`. Each is in a directory only you can enter; `--socket` on `termd`, `tsm-relay` and `tsm` names another. A remote machine is reached by running the relay there: `"command": "ssh", "args": ["box", "tsm-relay", "--scope", "AGENT"]`.
